# Changelog

## 1.1.4
- Added `config.jsonc` to the canonical source package.
- Updated the runtime loader from `config.json` to `config.jsonc`.
- Retained inline `//` descriptions with proper JSONC editor support.
- Added a build script that creates the final SPT drag-and-drop ZIP.

- Fixed SPT `Path` namespace collisions.
- Fixed invalid null-conditional usage on non-nullable `MongoId`.
- Added APBS and ORBIT compatibility behavior.
